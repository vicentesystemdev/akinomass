# Subdominio Plantillas

Este subdominio contiene la lógica relacionada con plantillas de mensajes predeterminadas para seguimiento comercial.

## Objetivo

Apoyar a usuarios con poca experiencia en redes sociales mediante mensajes sugeridos que puedan copiar, adaptar y usar manualmente.

## Responsabilidades

- Crear plantillas de mensajes.
- Clasificar plantillas por tipo.
- Asociar plantillas a estados de leads, pedidos o pagos.
- Sugerir mensajes según contexto comercial.
- Permitir activar o desactivar el uso de plantillas.

## Tipos sugeridos

- primer_contacto
- seguimiento
- confirmacion_interes
- confirmacion_pedido
- recordatorio_pago
- agradecimiento
- cliente_inactivo
- stock_disponible
- respuesta_rapida_live

## Reglas

- No enviar mensajes automáticamente.
- No integrar APIs externas de mensajería.
- No crear bots.
- Las plantillas son textos sugeridos.
- El usuario decide si copia, modifica o usa el mensaje.
- Usuarios con experiencia o bots externos pueden desactivar esta funcionalidad.
