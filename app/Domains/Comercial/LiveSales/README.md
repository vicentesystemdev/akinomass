# Subdominio LiveSales

Este subdominio contiene la lógica relacionada con ventas en vivo, orientada inicialmente a TikTok LIVE.

No representa una integración automática con TikTok ni con APIs externas.

## Objetivo

Permitir registrar manualmente sesiones de venta en vivo y organizar la información comercial generada durante una transmisión.

## Responsabilidades

- Crear sesiones de venta en vivo.
- Registrar productos ofrecidos en la sesión.
- Registrar interacciones observadas manualmente.
- Asociar alias o nombre del interesado.
- Registrar intención de compra.
- Convertir interacción en lead.
- Convertir lead o interacción en pedido.
- Generar resumen de sesión live.

## Ventas en vivo

El dominio Comercial incluye un subdominio LiveSales para gestionar ventas en vivo, orientado inicialmente a TikTok LIVE.

Este subdominio permite registrar sesiones, productos ofrecidos e interacciones manuales durante una transmisión.

No implica integración con la API de TikTok.

## Reglas

- No integrar API de TikTok en la primera versión.
- No leer comentarios automáticamente.
- No crear bots.
- No crear webhooks externos.
- Priorizar velocidad de registro manual.
- Mantener relación con canales de venta y pedidos.
